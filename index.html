ໃຊ້ຄັ້ງທຳອິດ? ອ່ານ

ຄູ່ມືການໃຊ້ງານ

ລະບົບນີ້ໃຊ້ຕິດຕາມໂຄງການງົບໂຄສະນາ Facebook ຂອງສາຂາ ໂນນຄໍ້ ແລະ ສີສະຫວາດ. ລູກຄ້າທັກເຂົ້າເພຈສາຂາ → ສາຂາບັນທຶກທຸກຄົນ → ລູກຄ້ານອກເຂດຖືກສົ່ງໃຫ້ ສນຫ ຕິດຕາມ → ເຈົ້າຂອງເບິ່ງຜົນທຸກວັນຈັນ.

  1. ສາຂາ ບັນທຶກລູກຄ້າທີ່ທັກເຂົ້າມາ ແລະ ຜົນການຂາຍ
  2. ສນຫ ໂທຫາລູກຄ້ານອກເຂດ ພາຍໃນ 24 ຊົ່ວໂມງ ແລ້ວແຈ້ງຜົນ
  3. ສາຂາ ຈ່າຍຄ່າໂຄສະນາເອງ ບັນທຶກເງິນທີ່ໃຊ້ທຸກມື້ ແລະ ຍື່ນເຄລມຄືນທຸກອາທິດ
  4. ເຈົ້າຂອງ / ຜູ້ຈັດການ ເບິ່ງແດຊບອດ, ກວດ ແລະ ຄືນເງິນເຄລມ

ສຳລັບພະນັກງານສາຂາ
  1. ເຂົ້າລະບົບ: ກົດ ເຂົ້າລະບົບ → ເລືອກຊື່ສາຂາ → ໃສ່ PIN ຂອງສາຂາ. ເຂົ້າຄັ້ງດຽວ ຢູ່ໄດ້ 30 ວັນ ໃນເຄື່ອງນັ້ນ.
  2. ບັນທຶກລູກຄ້າທຸກຄົນທີ່ທັກເຂົ້າມາ ພາຍໃນມື້ດຽວກັນ ເຖິງວ່າຈະຍັງບໍ່ຊື້ກໍ່ຕາມ. ຕ້ອງມີ ຊື່ ຫຼື ເບີໂທ ຢ່າງໜ້ອຍ 1 ຢ່າງ.
  3. ເລືອກເຂດ: ໃນເຂດ = ສາຂາສົ່ງເອງໄດ້. ນອກເຂດ = ສາຂາສົ່ງບໍ່ເຖິງ — ລະບົບຈະສົ່ງໃຫ້ ສນຫ ອັດຕະໂນມັດ ບໍ່ຕ້ອງໂທບອກ. ບໍ່ແນ່ໃຈ = ໃຊ້ຊົ່ວຄາວ ແລ້ວຕ້ອງກັບມາແກ້ເປັນ ໃນເຂດ ຫຼື ນອກເຂດ.
  4. ຕອບທັນ 30 ນາທີ: ເລືອກ ທັນ ຖ້າຕອບລູກຄ້າຄັ້ງທຳອິດພາຍໃນ 30 ນາທີ ຫຼັງລູກຄ້າທັກ. ຕອບຕາມຄວາມຈິງ — ຕົວເລກນີ້ໃຊ້ເບິ່ງວ່າສາຂາວຽກໜັກເກີນ ຫຼື ບໍ່.
  5. ຜົນ: ກຳລັງຕອບ = ຍັງຄຸຍຢູ່. ປິດການຂາຍໄດ້ = ລູກຄ້າສັ່ງຊື້ຄັ້ງທຳອິດແລ້ວ (ໃສ່ວັນທີ ແລະ ມູນຄ່າ). ບໍ່ສົ່ງຜົນ = ລູກຄ້າບໍ່ຊື້.
  6. ອັບເດດຜົນ: ໃນລາຍຊື່ລູກຄ້າ ກົດ ປິດການຂາຍໄດ້ / ບໍ່ສົ່ງຜົນ ໄດ້ເລີຍ. ກົດ ແກ້ໄຂ ເພື່ອແກ້ຂໍ້ມູນອື່ນ.
  7. ລຶບ: ລຶບໄດ້ພາຍໃນ 48 ຊົ່ວໂມງ ຫຼັງບັນທຶກ ແລະ ຕ້ອງເປັນລາຍການທີ່ ສນຫ ຍັງບໍ່ແຈ້ງຜົນ. ເກີນນັ້ນ ໃຫ້ແຈ້ງແອດມິນ.
  8. ຕົວເລກດ້ານເທິງ: ປິດການຂາຍໄດ້ ກີ່ຈຸດ, ສົ່ງໃຫ້ ສນຫ ກີ່ຄົນ, ສນຫ ປິດໄດ້ກີ່ຄົນ ແລະ ລໍຖ້າຜົນກີ່ຄົນ. ກົດ ເດືອນນີ້ / ເດືອນກ່ອນ / ທັງໝົດ ເພື່ອປ່ຽນຊ່ວງ.
  9. ລູກຄ້ານອກເຂດ: ບັນທຶກໃນແອັບ ເລືອກ ນອກເຂດ = ສົ່ງໃຫ້ ສນຫ ແລ້ວ — ແອັບຄືຫຼັກຖານດຽວ ບໍ່ຕ້ອງສົ່ງທາງອື່ນ. ໂຄງການນີ້ບໍ່ມີຄ່າສົ່ງຕໍ່. ຫຼັງ ສນຫ ແຈ້ງຜົນແລ້ວ ສາຂາປ່ຽນເຂດ ຫຼື ຜົນຂອງລູກຄ້າຄົນນັ້ນບໍ່ໄດ້.

ສຳລັບ ສນຫ
  1. ເປີດແຖບ ສນຫ ຕິດຕາມ ທຸກມື້ (ຢ່າງໜ້ອຍເຊົ້າ ແລະ ບ່າຍ). ລາຍການທີ່ລໍຖ້າດົນທີ່ສຸດຢູ່ເທິງສຸດ.
  2. ໂທຫາລູກຄ້າພາຍໃນ 24 ຊົ່ວໂມງ ນັບແຕ່ສາຂາສົ່ງມາ. ປ້າຍ ຄວນໂທດ່ວນ ຂຶ້ນເມື່ອຜ່ານ 12 ຊົ່ວໂມງ, ປ້າຍສີແດງ ເກີນ 24 ຊົ່ວໂມງ ຂຶ້ນເມື່ອເກີນກຳນົດ.
  3. ແຕະເບີໂທເພື່ອໂທ ຫຼື ກົດ ສຳເນົາເບີ. ອ່ານ ໝາຍເຫດຈາກສາຂາ ກ່ອນໂທ.
  4. ບັນທຶກສັ້ນໆ ໃນຊ່ອງ ບັນທຶກ ສນຫ ແລ້ວກົດຜົນ: ປິດການຂາຍໄດ້ = ລູກຄ້າສັ່ງຊື້ກັບ ສນຫ ແລ້ວ. ປິດບໍ່ໄດ້ = ລູກຄ້າບໍ່ເອົາ. ຍັງລໍຖ້າ = ໂທບໍ່ຕິດ ຫຼື ນັດໃໝ່.
  5. ກົດ ປິດການຂາຍໄດ້ ເມື່ອລູກຄ້າສັ່ງຊື້ແລ້ວແທ້ເທົ່ານັ້ນ — ຕົວເລກນີ້ນັບເປັນລູກຄ້າໃໝ່ຂອງໂຄງການ.
  6. ຖ້າກົດຜິດ ກົດປຸ່ມຜົນທີ່ຖືກຕ້ອງໃໝ່ໄດ້ເລີຍ.

ສຳລັບເຈົ້າຂອງ / ຜູ້ຈັດການແຟຣນໄຊ (ແອດມິນ)

ເລີ່ມໃຊ້ຄັ້ງທຳອິດ

  1. ເຂົ້າລະບົບເປັນ ແອດມິນ → ແຖບ ແອດມິນ → ປ່ຽນ PIN ຂອງແອດມິນກ່ອນ.
  2. ແຖບ ແອດມິນ → ໄລຍະໂຄງການ: ຕັ້ງ ວັນເລີ່ມໂຄງການ ແລະ ຈຳນວນເດືອນ (3) — ງົບ 100 ໂດລາ ນັບເປັນເດືອນລະ 1 ຮອບ ຈາກວັນເລີ່ມ.
  3. ກົດ ເປີດ ຕັ້ງຄ່າ ແລ້ວຕື່ມ: ອັດຕາແລກປ່ຽນ, ກຳໄລຂັ້ນຕົ້ນຕໍ່ລູກຄ້າຕໍ່ເດືອນ ແລະ ອາຍຸລູກຄ້າສະເລ່ຍ. ລະບົບບັນທຶກເອງ ທຸກຄົນເຫັນຄືກັນ.
  4. ແຈກ PIN ໃຫ້ສາຂາ ແລະ ສນຫ ແບບສ່ວນຕົວ (ບໍ່ສົ່ງໃນກຸ່ມ). ສົ່ງລິ້ງໜ້ານີ້ໃຫ້ເຂົາເຈົ້າເປີດໃນມືຖື ແລະ ເພີ່ມໃສ່ໜ້າຫຼັກ (Add to Home Screen).

ທຸກວັນຈັນ (10 ນາທີ)

  1. ເປີດ ແດຊບອດ (ຊ່ວງ ເດືອນນີ້). ອ່ານແຖບເຕືອນສີເຫຼືອງກ່ອນ.
  2. ກວດແຖບ ເງິນໂຄສະນາ: ທຸກສາຂາບັນທຶກເງິນທີ່ໃຊ້ຄົບທຸກມື້ ແລະ ເຄລມອາທິດກ່ອນຖືກກວດແລ້ວ — ແດຊບອດເອົາເງິນທີ່ໃຊ້ຈາກບ່ອນນັ້ນໄປຄຳນວນເອງ.
  3. ເບິ່ງປ້າຍຜົນຕັດສິນຂອງແຕ່ລະສາຂາ: ຂະຫຍາຍ / ຕໍ່ ແລະ ປັບ / ຢຸດ. ຕັດສິນໄດ້ ເມື່ອໄດ້ຜົນຄືກັນ 2 ເດືອນຕິດຕໍ່ກັນ.
  4. ກວດເຄລມທີ່ ສນຫ ອະນຸມັດແລ້ວ ແລະ ຄືນເງິນໃຫ້ສາຂາ — ກົດ ບັນທຶກວ່າຄືນເງິນແລ້ວ ພ້ອມຈຳນວນ ແລະ ວັນທີ.

ອື່ນໆ

  • ແຖບ ບັນທຶກລູກຄ້າ: ແອດມິນເລືອກສາຂາ ແລ້ວເພີ່ມ/ແກ້/ລຶບ ລູກຄ້າແທນສາຂາໄດ້.
  • ແຖບ ແອດມິນ → ດາວໂຫຼດ CSV: ໄດ້ໄຟລ໌ທີ່ມີຖັນ A–P ຄືກັບແຜ່ນ ບັນທຶກລູກຄ້າ ໃນ Excel.
  • ພິມເຂົ້າທີ່ປະຊຸມ: ເປີດແດຊບອດ ແລ້ວກົດ Ctrl+P (⌘+P ໃນ Mac). ເບີໂທລູກຄ້າບໍ່ຖືກພິມ.
  • ພະນັກງານລາອອກ ຫຼື PIN ຮົ່ວ: ປ່ຽນ PIN ຂອງຝ່າຍນັ້ນທັນທີ — ເຄື່ອງທີ່ໃຊ້ PIN ເກົ່າຈະຖືກອອກຈາກລະບົບ.

ເງິນໂຄສະນາ: ບັນທຶກລາຍວັນ ແລະ ເຄລມ (ແຖບ ເງິນໂຄສະນາ)

ສາຂາຈ່າຍຄ່າໂຄສະນາ Facebook ເອງ (ບັດ ຫຼື ບັນຊີຂອງສາຂາ) ແລ້ວເຄລມຄືນຈາກ ສນຫ ທຸກອາທິດ. ງົບ 100 ໂດລາ ຕໍ່ເດືອນ ຕໍ່ສາຂາ. ຫ້າມເກີນ — ເມື່ອໃຊ້ຮອດ 100 ໂດລາ ຕ້ອງຢຸດໂຄສະນາ. ສ່ວນທີ່ເກີນ ເຄລມບໍ່ໄດ້.

ສຳລັບສາຂາ

  1. ທຸກມື້: ເປີດ Ads Manager ເບິ່ງ ຈຳນວນທີ່ໃຊ້ (Amount spent) ຂອງມື້ນັ້ນ → ແຖບ ເງິນໂຄສະນາ → ໃສ່ວັນທີ ແລະ ເງິນທີ່ໃຊ້ເປັນໂດລາ → ບັນທຶກ. ມື້ທີ່ບໍ່ໄດ້ຍິງ ໃສ່ 0. ບັນທຶກມື້ກ່ອນໄດ້ ຖ້າລືມ.
  2. ເບິ່ງແຖບສີ: ສະແດງວ່າເດືອນນີ້ໃຊ້ໄປເທົ່າໃດ ຈາກ 100 ໂດລາ. ຮອດ 80% ຂຶ້ນເຕືອນ. ຮອດ 100% ຢຸດໂຄສະນາທັນທີ. ແນະນຳຕັ້ງວົງເງິນໃນ Ads Manager ບໍ່ໃຫ້ເກີນ 100 ໂດລາ/ເດືອນ.
  3. ທຸກວັນຈັນ: ຍື່ນເຄລມອາທິດທີ່ຜ່ານມາ (ຈັນ–ອາທິດ): ກົດ ຍື່ນເຄລມ → ໃສ່ຍອດກີບ ຕາມໃບບິນ Facebook ຫຼື ລາຍການບັດຂອງສາຂາ ແລະ ເລກອ້າງອີງ.
  4. ຄືນເງິນ = ຍອດກີບ × (ໂດລາທີ່ເຄລມໄດ້ ÷ ໂດລາທີ່ໃຊ້). ຖ້າບໍ່ເກີນງົບ ໄດ້ຄືນເຕັມຍອດກີບ.
  5. ຫຼັງຍື່ນເຄລມ ແກ້ເງິນລາຍວັນຂອງອາທິດນັ້ນບໍ່ໄດ້. ຖ້າ ສນຫ ສົ່ງກັບໃຫ້ແກ້ ອ່ານໝາຍເຫດ, ແກ້ ແລ້ວຍື່ນໃໝ່.

ສຳລັບ ສນຫ

  1. ທຸກວັນຈັນ–ອັງຄານ: ເປີດແຖບ ເງິນໂຄສະນາ ກວດເຄລມທີ່ຂຶ້ນ ລໍ ສນຫ ກວດ. ທຽບຍອດກີບ ກັບໃບບິນ/ລາຍການບັດທີ່ສາຂາສົ່ງໃຫ້.
  2. ຖືກຕ້ອງ ກົດ ອະນຸມັດ. ບໍ່ຖືກ ກົດ ສົ່ງກັບໃຫ້ແກ້ ແລະ ຂຽນເຫດຜົນ.
  3. ເມື່ອໂອນເງິນຄືນໃຫ້ສາຂາແລ້ວ ກົດ ບັນທຶກວ່າຄືນເງິນແລ້ວ ໃສ່ຈຳນວນ ແລະ ວັນທີ.
  4. ເບິ່ງ 14 ມື້ລ່າສຸດຂອງແຕ່ລະສາຂາ: ມື້ສີເຫຼືອງ = ຍັງບໍ່ໄດ້ບັນທຶກ — ທັກສາຂາໃຫ້ບັນທຶກ.
